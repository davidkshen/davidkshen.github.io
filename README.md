# David Shen

Professional portfolio featuring private equity sourcing, student leadership, research, education, and contact information.

Built with HTML, CSS, and JavaScript. No dependencies or build step.

## Local preview

Run `python3 -m http.server 8000` from this directory and open http://localhost:8000.

## GitHub Pages

Publish the root folder of the main branch using GitHub Pages. Relative asset links support either a project URL or a custom domain.
